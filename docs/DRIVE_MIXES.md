# Too Hot for Mixcloud

The section below Latest Mixes is ready for supplied Google Drive links. Add objects with `title` and `url` to the `mixes` array in `public/drive-mixes.json`, in display order. Links open the audio file on Google Drive in a new tab. Use individual audio-file sharing links rather than folder links. Confirm listener access and playback once links are supplied; this feature does not change Drive sharing permissions. Until then the section displays “Mixes coming soon.”
